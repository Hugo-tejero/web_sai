# Descubre tu SAI

Web interactiva que explica los SAI a clientes sin conocimientos técnicos. El contenido técnico sale de la Guía Técnica SAI de Legrand (2013); cada dato indica su página.

Archivos: `index.html`, `style.css` y `script.js`. No necesita instalar nada.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (público).
2. Sube los tres archivos a la raíz del repositorio (`Add file` > `Upload files`).
3. Ve a `Settings` > `Pages`. En `Source` elige `Deploy from a branch`, rama `main` y carpeta `/ (root)`. Guarda.
4. Espera uno o dos minutos. La web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
